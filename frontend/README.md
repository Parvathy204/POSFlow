# POSFlow frontend

React 19 + Vite client for the POSFlow retail billing suite.

From this folder:

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api to localhost:5000
npm run build    # production build in dist/
npm run lint
```

The full project overview, live URLs, test accounts, API map and deployment
instructions are in the repository root [`README.md`](../README.md).
